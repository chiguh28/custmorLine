# エステサロン向け LINE公式アカウント連携システム

LINE公式アカウントを2つ（客用・セラピスト用）使用した、情報配信・管理システムです。
お客様には最新の料金表や出勤表を提供し、セラピストはスマホから簡単に出勤表を更新・一斉配信できます。

## システム構成

*   **客用アカウント (Customer Bot)**: お客様向け。リッチメニューから情報を閲覧したり、更新通知を受け取ったりします。
*   **セラピスト用アカウント (Therapist Bot)**: スタッフ向け。出勤表画像のアップロードと一斉配信の操作を行います。

## 主な機能

### 1. 客用アカウント機能
*   **料金表の表示**: リッチメニューの「料金表」をタップすると、設定された料金表画像を送信します。
*   **出勤表の表示**: リッチメニューの「出勤表」をタップすると、最新の出勤表画像を送信します。
*   **更新通知の受信**: セラピストが出勤表を更新すると、自動的にメッセージと画像が届きます。

### 2. セラピスト用アカウント機能
*   **出勤表の更新**: 「出勤情報登録」ボタンから、新しい出勤表画像をアップロードできます。
*   **一斉配信**: アップロードした画像を、登録されている全友だち（お客様）へ一斉配信します。
*   **プレビュー確認**: 配信前に、画像と対象人数を確認できます。

## 技術スタック
*   Python 3.10+
*   Flask
*   LINE Messaging API (line-bot-sdk)
*   SQLite (友だちリスト・状態管理)

## セットアップ & 実行方法

### 必要要件
*   Python 3.10以上
*   LINE公式アカウント 2つ
*   Ngrok (ローカル開発用) または Render等のホスティング環境

### ローカルでの実行
詳細な手順は [README_LOCAL.md](README_LOCAL.md) を参照してください。

1.  依存ライブラリのインストール: `pip install -r requirements.txt`
2.  環境変数の設定: `.env` ファイルを作成し、LINE APIキーを設定。
3.  アプリの起動: `start_app.bat`
4.  Ngrokの起動: `start_ngrok.bat`
5.  LINE Developers ConsoleでWebhook URLを設定。

### リッチメニューの設定
リッチメニューのボタン設定については [SETUP_RICH_MENU.md](SETUP_RICH_MENU.md) を参照してください。
**URLではなく「テキスト」アクションを設定する必要があります。**
